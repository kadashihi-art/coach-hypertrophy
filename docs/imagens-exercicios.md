# Imagens dos exercícios

Cada imagem mostra duas posições do movimento (início e fim), lado a lado.

## Fonte e licença

- **Free Exercise DB**: https://github.com/yuhonas/free-exercise-db
- **Licença:** The Unlicense, ou seja, domínio público. Não exige atribuição, mas o crédito aparece mesmo assim na imagem ampliada ("Imagem: Free Exercise DB (domínio público)").
- **Sem hotlink:** os JPGs originais foram baixados uma vez, juntados (posição 0 + posição 1), reduzidos para 240 px de altura e convertidos em WebP (qualidade 70). Ficam em `public/exercicios/`.
- **Sem chave de API.**

## Regra de uso

1. Se o exercício tem imagem própria (tabela abaixo), ela é usada.
2. Se é uma variação sem imagem própria, usa a imagem do exercício-base (`base_id`).
3. Se não tem nenhuma das duas, a tela mostra um placeholder neutro.

O mapa fica em `src/lib/catalog/imagens.ts`, e o `npm run smoke:imagens` confere a cobertura e se os arquivos existem.
